# Mango Code Templates

This directory is the canonical source for code generated by Mango tooling and
AI-assisted development. Published PMO baselines, the business starter, and the
CLI may project these files, but they must not maintain independent variants.

Templates are executable examples of Mango conventions. The rule coverage in
`index.json` maps each applicable Mango rule to template files and machine
checks. `qualityProfiles` binds generated Java to Mango's own Checkstyle and
architecture rule implementations; `conventions` proves the concrete template
locations for module/package layout, `XxxCode implements BizCode`, `Require`,
Mango CRUD, tenant persistence, resources, migrations, frontend exports, and
tests. Rules remain authoritative in `rules/**`; template comments must not copy
rule text.

Generation uses declared input and derived variables only. Renderers must reject
unknown variables, unsafe path values, and unresolved `{{...}}` placeholders.
