## Fixed

- Resource Registry FINALIZE now logs and skips historical rows with missing `tenant_id` without guessing a tenant, invoking a handler, or modifying the row.
- Real-tenant rows and other cleanup failures retain the existing fail-closed behavior.

## Added

- Added integration coverage and delivery evidence for legacy tenantless Resource Registry rows.

## Changed

- Maven/docs and all non-application Mango Maven coordinates advance from `1.1.3` to `1.1.4` in generated topology order.
- `@mango/cli` advances from `1.3.8` to `1.3.9` as the generated CLI compatibility closure for Maven `1.1.4`.

## Business Impact

- Backend consumers with historical Resource Registry rows lacking `tenant_id` can complete FINALIZE without a guessed tenant or mutation of those rows.
- Consumers with real tenant ownership continue to receive the existing cleanup and failure semantics; no tenant or authorization data is inferred or rewritten.
- This batch contains a backend behavior fix and Maven/docs publication; consumers must not mix Maven `1.1.4` with npm packages from another release batch except the explicitly planned CLI `1.3.9`.
