## Business Impact

- Empty-database consumers whose Authorization manifest encounters a cross-module parent menu before its provider module can complete Bootstrap in the first formal startup without a second application start.
- Administrators can filter members by an organization and enabled descendants, switch to all members, create an account directly in an organization, and inspect or assign roles using batch-loaded summaries.
- New Org, Identity and Authorization Java/HTTP contracts are additive. Existing user, organization and role permissions remain authoritative; no administrator fallback, database migration or production data mutation is introduced.
- Direct frontend consumers must upgrade the complete generated npm closure because exact runtime dependencies advance together. This release publishes platform artifacts only and does not deploy a business application.
