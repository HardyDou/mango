## Business Impact

- Workflow consumers can reuse one data-permission contract across business-apply reads. Existing default authorization continues to recognize creator, current assignee and users who handled a task; custom rules are selected by workflow code and remain tenant-scoped.
- Resource Bootstrap now honors declaration-level module dependencies for cross-module menus. Missing dependencies, cycles and conflicting repeated declarations fail before handlers execute.
- Existing aggregate consumers receive the built-in menu ordering through Maven `1.0.41`. Direct Resource authors only need changes when they maintain their own cross-module declarations.
- There is no database schema migration, application deployment, traffic change, automatic permission grant or application fat-JAR publication in this component release.

- Audience: Mango platform maintainers, generated applications, and direct consumers of Workflow business-apply or Resource declaration APIs.
- Engineering Effort: 30 to 90 minutes for generated aggregate consumers; 1 to 3 hours for direct consumers that add custom Workflow permission providers or Resource dependencies.

## Upgrade Notes
