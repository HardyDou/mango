## Business Impact

- Mango `1.0.44` consumers affected by candidate-group task startup failures or blocked Workflow callbacks can upgrade without a database migration. The new internal callback path requires the existing signed internal-request configuration and never accepts caller-supplied tenant or owner coordinates.
- Workflow template push, Home list and Home user pages use domain-owned option APIs under their existing page permissions. No additional broad System or Identity list permission should be granted.
- Resource Registry stops repeated unchanged writes after the first successful cycle in one process. Application restart intentionally resets the in-memory fingerprint, and a failed submission does not advance it.
- PMO consumers receive clarified Skill routing only. This component release does not deploy a business application, change traffic or mutate production data.
