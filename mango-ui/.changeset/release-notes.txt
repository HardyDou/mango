## Business Impact

- Reset consumers can restore the deterministic portable Resource database baseline and avoid repeating baseline Resource handlers after restore; existing databases continue normal Flyway and incremental Resource rules.
- Workflow consumers get stable tenant-scoped assignment and Provider-backed candidate contracts.
- PMO consumers receive the `1.4.3` document lifecycle contract and generated project projection. This is a component release only; it does not deploy an application or mutate test/production environments.

## Upgrade Estimate

- Audience: Mango maintainers, generated applications, Resource Bootstrap consumers, Workflow API/UI consumers and PMO-managed business repositories.
- Engineering Effort: 30 to 90 minutes for generated consumers; 1 to 3 hours for direct Workflow or custom Resource-handler consumers.
- Execution Window: 1 to 3 hours including dependency upgrade, Flyway, clean reset/incremental verification and PMO locked checks.
- Service Downtime: no framework-mandated downtime; consumers use their normal restart and migration window.
- Rollback Effort: 15 to 45 minutes to restore Maven `1.0.43`, PMO `1.4.2`, CLI `1.2.3` and the prior exact npm tuple; database rollback follows the consumer's reviewed procedure.
- Assumptions: Node `22.23.1`, Java 21, clean dependency locks, configured registries, one local MySQL datasource and tenant-scoped Workflow test data.
