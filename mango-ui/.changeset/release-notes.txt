## Pull Requests

- [PR #939](https://github.com/HardyDou/mango/pull/939) Fixed Identity Resource initialization so tenant-member lifecycle IDs and timestamps are deterministic across repeated BSQL builds and new production databases. Packages: Mango Maven `1.0.50`, `io.mango:mango-docs-bundle:1.0.50`, and generated consumer lock `@mango/cli@1.2.10`. Business Adaptation: keep stable Identity user/member IDs, declare a fixed `initializedAt` value, regenerate BSQL, and verify two clean builds produce identical Identity snapshots.

## Fixed

- Derive the initial tenant-member lifecycle-log ID from the stable tenant ID, member ID, and `CREATED` event instead of a runtime-generated MyBatis-Plus ID.
- Use the declared `initializedAt` value for initial user, membership, and lifecycle timestamps instead of the build clock, so identical declarations produce identical BSQL data.

## Changed

- Require `initializedAt` with `DATETIME` syntax on `IDENTITY_USER` Resource declarations and reject missing or invalid values before any initialization write.
- Advance generated consumers to Mango Maven `1.0.50` through `@mango/cli@1.2.10`; `@mango/pmo@1.4.4` and all other npm package versions remain unchanged.

## Versions

- Mango Maven non-application reactor and `io.mango:mango-docs-bundle`: `1.0.49` to `1.0.50` (192 machine-generated coordinates).
- `@mango/cli`: `1.2.9` to `1.2.10`; `@mango/pmo` remains `1.4.4`; all other npm package versions remain unchanged.

## Business Impact

- Rebuilding BSQL from the same Identity Resource declaration now produces the same user, tenant-member, and lifecycle rows, including IDs and timestamps, across build times and new production databases.
- Stable-ID collisions, missing `initializedAt`, and invalid timestamps fail before user or member writes; normal API create, remove, and restore operations retain runtime IDs and real event times.
- No database schema migration, API path, permission code, tenant boundary, runtime lifecycle-audit semantic, or business application deployment is included.
