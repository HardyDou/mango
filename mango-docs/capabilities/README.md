# Mango 能力地图

## 1. 定位

本文用于帮助 Mango 开发者、业务开发者和 AI Agent 快速定位 Mango 能力、模块 README、关联 PMO 规则和排障入口。

长期规则仍以 `mango-pmo` 为唯一来源；本文只做能力索引，不复制规范正文。

2026-08-28 能力更新：Workflow 办理人身份字段统一为原始 Flowable `assigneeName` 加当前租户解析的 `assigneeId`、`assigneeDisplayName`；详见 Workflow、Identity README 与业务审批接入指南。

2026-08-29 能力更新：Issue #851 的构建期 Resource baseline 对 Authorization、Calendar、Identity 等正式 Resource 使用固定 ID 或稳定业务身份生成确定性主键，并在写 BSQL 前把非空审计时间规范化为固定值；`publish_time` 等业务时间不被忽略或改写。相同输入会生成相同 BSQL、manifest 与 generation fingerprint，普通业务列、主键或资源事实差异仍会阻断构建。详见 Resource、Authorization、Calendar、Identity、Notice 与 Mango Tools README。

## 2. 使用方式

1. 先按任务关键词找到涉及能力。
2. 阅读能力对应的模块 README。
3. 查看关联 PMO 链接；正式交付规则以 preflight 输出和 `mango-pmo/rules/**` 为准。
4. 能力说明维护要求见 [能力说明维护规范](../../mango-pmo/rules/08-capability-docs.md)。

处理 Mango 升级、初始化数据、字典、菜单、角色、工作流、Flyway 或 demo 数据时，先看本页“近期能力变更”，再看对应模块 README。历史 migration、历史设计和旧会话上下文只能作为历史证据；如果它们和当前 README 或本页冲突，以当前 README、本页和明确标注为当前口径的设计为准。

- 2026-08-25，AI 初始化接入 Resource Registry：正式资源以 `INIT_ONLY` 内置八个空密钥、默认停用的供应商连接及每家一个代表模型，租户已有配置不被覆盖；通用对话、合同五要素抽取和文本情感分类三个服务示例放在 `META-INF/mango/demo/`，仅在 `mango.resource.registry.demo-enabled=true` 时加载。`AI_PROVIDER_CONNECTION`、`AI_MODEL`、`AI_PROMPT`、`AI_SKILL`、`AI_SERVICE` 均已有目标 Handler，Flyway 继续只负责 V1-V10 表结构演进，不新增数据 seed。接入细节见 [Extension README](../../mango/mango-extension/README.md) 和 [Resource Registry README](../../mango/mango-platform/mango-resource/README.md)。
- 2026-08-25，AI 服务收敛为统一多模态会话：对话、信息抽取、文本分类均进入 `/ai/services/run`，只通过 `POST /ai/services/chat` 标准受理、Mango Realtime `ai.service.chat` 增量事件和 `DELETE /ai/services/chat` 停止生成。用户消息支持文本和受模型真实模态约束的图片、音频、视频、PDF/文本文件；附件可选择、拖拽或粘贴，提供本地预览、真实进度、取消和失败重试。结果可展示安全富文本、结构化 JSON、图片、视频、音频和普通文件。附件只保存 Mango `fileId`，模型不支持的模态在上传前和服务端双重拒绝；Responses 适配器显式支持文本、图片与 PDF/文本文件，当前适配器不声明音频或视频理解能力。同一会话支持按轮选择模型和深度思考：发送时冻结当前轮设置，生成期间调整只影响下一轮，助手消息持久化并显示本轮实际设置；附件与目标模型不兼容时阻止切换，不删除、不 fallback。跨实例取消通过共享 KV 标记生效，重复请求、非所有者取消和 Realtime 投递失败均 fail-closed 并进入审计。Flyway V9 把历史消息迁移为内容块并删除旧字符串列，V10 删除会话绑定字段语义并增加消息级模型事实；旧同步 `/ai/services/invoke`、AI 自有 SSE、Schema 表单运行器、会话锁定和运行时 fallback 均已删除。会话、限流、熔断、审计和 Token 按租户、用户、服务和 session 隔离。Spring Boot 保持 3.5.14，Spring AI 保持 1.1.8。接入和验收见 [Extension README](../../mango/mango-extension/README.md)、[AI 验收证据](../evidence/baselines/ai/latest/acceptance.md) 和 [AI 服务调用设计](../plans/2026-08-24-ai-service-invocation-design.md)。
- 2026-08-22，AI 模型管理完成领域优化：新增租户级供应商接入、供应商下多模型目录、多能力/多模态声明和按能力默认路由；`ai-menu.json` 在“平台能力 → AI 管理”下注册“模型管理”双栏页面。支持 DeepSeek、火山方舟、阿里云百炼、智谱 AI、硅基流动、Kimi、OpenAI 兼容协议和 Ollama 的接入配置；运行时只将已实现的 Chat 适配器标为可调用。
