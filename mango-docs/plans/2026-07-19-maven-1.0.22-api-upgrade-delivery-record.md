# 标准交付记录

任务：Maven 1.0.22 Java API 升级说明

## 1. 元数据

- 任务 ID：MAVEN-1.0.22-API-UPGRADE
- 交付模式：STANDARD
- 需求影响：L2 - 1.0.21 业务源码因多个已删除公共类型无法编译升级
- 方案风险：L1 - 仅补充已发布版本的迁移说明和索引，不改变运行时契约
- 最终风险：L2
- 工作区决策：REUSE，复用为本任务创建的 `docs/maven-1.0.22-api-upgrade` worktree

## 2. 目标与范围

- 目标：给出 1.0.21 到 1.0.22 的明确 Java API 升级方案。
- 成功条件：业务开发者能从编译错误定位替代类型、依赖、调用方式、升级顺序和验证命令。
- 处理范围：1.0.21 与 1.0.22 tag 之间删除或迁移的业务可消费 Java API、CHANGELOG、Identity README、能力地图和业务指南索引。
- 不处理范围：恢复旧 API 兼容类、修改 1.0.22 制品、修改运行时行为、数据库 schema 或业务项目代码。

## 7. 例外与剩余风险

- 本任务不改变 Maven 制品，不能让未迁移的旧源码直接兼容 1.0.22；业务项目仍需按指南修改并完成自身回归。
- 已发布的 Maven 1.0.22 尚未包含 #588 的 worktree 基线修复，使用该版本的业务仓只能按指南在忽略目录中临时归一化验证文件；不得提交临时基线或放宽门禁。
