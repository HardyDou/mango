# 文件访问权限基线实施计划

## 目标

统一文件模块访问模型：匿名用户只能通过不可猜测、短时有效的能力链接预览或下载；任意登录用户均可读取、上传、分片、秒传、批量、打包及合并；归档、删除、列表与管理配置继续使用细粒度权限。

## 实施步骤

1. 将文件详情、预览、下载、上传及衍生操作统一标记为 `LOGIN`，保留列表、归档、删除及管理接口的 `PERMISSION`。
2. 增加登录态签发、匿名态消费的短时文件访问链接；令牌保存租户上下文、文件、动作和过期时间，消费时重新校验文件状态。
3. 删除前端页面与公共组件对旧查询、上传、下载角色权限的默认依赖，并移除资源菜单中的陈旧授权项。
4. 增加访问模式、匿名令牌、过期/篡改、动作隔离及危险操作权限回归测试。
5. 运行文件模块定向测试、前端类型检查和运行态验证，确认无角色登录用户与匿名能力链接均符合基线。

## 回滚

代码与资源声明按提交整体回滚；短时令牌无数据库结构，停止签发并等待 TTL 到期即可失效。
