# Issue #919 成员移出与恢复生命周期验收证据

## 1. 验收范围

- 页面：Mango Admin `/#/system/user` 成员管理页、新增成员与恢复原成员弹框。
- 接口：`DELETE /org/members`、`DELETE /identity/users/{id}`、`GET /identity/users/account-availability`、`POST /org/member-accounts/restore`、成员角色与登录接口。
- 权限：默认租户 `default` 的管理员从正式菜单入口执行；临时第二租户通过正式机构接口创建。
- 数据：使用 `E2E_LIFECYCLE_<timestamp>`、`E2E_LIFECYCLE_OTHER_<timestamp>`、`e2e_ml_<timestamp>` 隔离数据；成员和组织通过正式接口清理，临时租户最终归档。
- 部署形态：Mango Admin 单体开发态，真实后端、MySQL 隔离数据库和 Chromium 浏览器。
- 时间边界：只验收 2026-09-01 起由本特性写入生命周期事件的成员，不验证或回填历史物理删除数据。
