## 2. 表单管理

| 编号 | 操作 | 预期结果 |
|---|---|---|
| A0 | 筛选不到任何表单 | 列表空态提示「没有匹配的表单，试试调整筛选条件」；全部为空时提示去新增 |
| A1 | 打开表单管理，观察列表 | 侧边菜单「信息采集管理」下只有「表单管理」；列与原型一致：表单名称 / 表单编码 / 备注 / 状态 / 提交量 / 创建日期 / 更新日期 / 创建人 / 操作；行操作只保留 详情、配置、提交记录、停用、删除（不再有「接入」，接入内容已并入详情页） |
| A2 | 点击「详情」 | 进入表单详情页：返回列表页返回栏 + 提交记录/配置表单按钮；3 列描述表（表单名称/编码/备注/提交量/创建日期/更新日期）；字段配置表（字段标签/编码/类型/必填/提示文字/排序）；接入方式区（提示语 + 模拟浏览器预览 + 左页面/右接口两张卡片） |
| A3 | 点击「配置」 | 进入表单设计页：顶部为表单名称/编码/状态/备注/提交成功提示，下方直接是平台表单设计器（组件面板、可拖拽画布、字段属性面板、预览），与工作流表单设计器同源 |
| A4 | 观察「保存配置」按钮初始状态 | 无改动时按钮禁用；在设计器里点一下或改任意设置后出现「有未保存的修改」并可保存 |
| A4-1 | 设计器内拖动控件调整顺序、点选字段修改属性后保存 | 顺序和属性保存成功；重新打开页面后与保存前一致 |
| A4-2 | 有未保存修改时点「返回列表页」 | 弹出离开确认；刷新或关闭标签页浏览器给出离开提示 |
| A5 | 新建表单时使用已存在编码 `customer-contact` | 后端拒绝并提示「信息采集表单编码已存在」（错误码 105501） |
| A6 | 删除「客户联系表」 | 因为已有提交记录，提示「已有提交记录的表单不可删除」（错误码 105505） |
| A7 | 新增表单并选择「停用」，再匿名打开托管地址 | 停用表单不可公开访问，提示表单未发布 |
| A8 | 在详情页查看接入方式 | 上方是模拟浏览器窗口（圆角、投影、白色地址栏），窗口内预览真实表单；下方左侧「方式 ① · 页面接入」给出免登录地址与复制按钮，右侧「方式 ② · 接口接入」给出接口路径与 `X-Mango-SK`；SK 可「显示/隐藏」「复制」，重新生成后旧密钥失效并提示同步到服务端环境变量 |
| A9 | 在表单详情页的接入卡片点击「复制地址」「打开页面」「复制接口」 | 分别复制托管地址、打开托管页面、复制接口路径；剪贴板不可用时给出手动复制提示 |

## 3. 提交记录

| 编号 | 操作 | 预期结果 |
|---|---|---|
| B1 | 从左侧菜单进入「提交记录」 | 是独立菜单入口，页面没有返回按钮；顶部筛选框为「表单 / 关键字 / 状态」＋查询/重置，列表右上角是「N 条待处理」与「导出记录」；列为记录ID / 提交时间 / 状态 / 来源页面 + 当前表单动态采集项列 + 操作 |
| B10 | 在顶部筛选框切换另一张字段不同的表单后查询 | 列表列随该表单字段定义变化，只显示本表单采集项；展示型/布局型控件不生成列；选择型控件显示选项标签 |
| B2 | 观察「导出当前筛选」按钮初始状态 | 有数据时可点击 |
| B3 | 点击行操作「处理」 | 右侧抽屉展示提交详情：标题为第一个采集项取值、时间 · 来源 · 匿名提交、状态、字段卡片（按原值展示，不脱敏）、展示说明、处理备注与处理状态 |
| B3-1 | 直接点击表格行 | 同样打开提交详情抽屉；来源页面列显示域名+路径，悬浮可见完整地址 |
| B4 | 在抽屉内选择「已完成」并点击「保存并更新」 | 抽屉关闭，列表状态变为「已完成」 |
| B5 | 在抽屉内选择「已关闭」后保存 | 状态变为「已关闭」，再次打开抽屉时「保存并更新」不可用，接口返回已关闭错误 |
| B6 | 按状态筛选「待处理」再查询 | 列表只返回待处理记录，分页总数同步变化 |
| B7 | 按关键字筛选记录ID片段 | 列表按记录ID匹配 |
| B8 | 点击「导出记录」 | 下载 CSV，列包含记录ID、提交时间、状态、来源页面和当前表单采集项；手机号形如 `136****00`，不含完整号码 |
| B9 | 观察列表与抽屉中的手机号 | 列表和抽屉同样脱敏为 `136****00`，与导出规则一致 |

## 5. 服务端 API 接入

当前表单专属 SK：`pWE5WUNzMU7E6Y4jn0wtueyXx6vX5tH8P`（可在表单详情复制核对）。

```bash
# 正确 SK 提交
curl -s -X POST http://127.0.0.1:18084/information/open/forms/submit \
  -H 'Content-Type: application/json' \
  -d '{"formCode":"customer-contact","values":{"name":"服务端测试","phone":"13500135000","need":"人工验收"},"sourcePage":"manual-check","serverSecret":"pWE5WUNzMU7E6Y4jn0wtueyXx6vX5tH8P"}'

# 错误 SK 应被拒绝（105507）
curl -s -X POST http://127.0.0.1:18084/information/open/forms/submit \
  -H 'Content-Type: application/json' \
  -d '{"formCode":"customer-contact","values":{"name":"x","phone":"1"},"serverSecret":"wrong"}'
```

| 编号 | 操作 | 预期结果 |
|---|---|---|
| D1 | 使用正确 SK 提交 | 返回 `id` 与成功提示语 |
| D2 | 使用错误 SK 提交 | 返回 `105507 服务端密钥无效`，且不产生记录 |
| D3 | 匿名 `GET /information/open/forms/detail?formCode=customer-contact` | 返回表单名称、说明、字段定义和成功提示，不包含 SK |
| D4 | 匿名调用后台接口 `GET /information/forms/page` | 返回 HTTP 401，后台接口不对匿名开放 |
