- 页面：Mango Admin `/#/system/user` 成员管理页、新增成员弹框、添加已有成员弹框、分配成员角色弹框。

- 权限：A 公司租户 `company_a` 的管理员从正式菜单入口执行；Issue #910 负责的菜单 Resource 重放仅作为本地验收前置，不属于 #909 源码范围。
