## 查找原则

- 当前能力和接入方式：回到对应场景或模块 README。
- 某次发布的完整范围：优先查看根 [CHANGELOG](../../CHANGELOG.md)、Git tag 或 Release manifest。
- 某个 Issue 的设计、验证和人工证据：查看 `mango-docs/designs/**`、`mango-docs/plans/**` 和 `mango-docs/evidence/**`。
- 长期流程规则：只查看 `mango-pmo/rules/**`，不要把本页当作规范来源。
