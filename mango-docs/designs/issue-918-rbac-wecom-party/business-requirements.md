# Issue #918 RBAC 与企微主体一致性业务需求说明书

## 1. 业务背景与问题

| 问题ID | 当前现状                                       | 业务问题                                              | 影响对象                 | 影响程度         | 事实来源                                                    |
| ------ | ---------------------------------------------- | ----------------------------------------------------- | ------------------------ | ---------------- | ----------------------------------------------------------- |
| BP-001 | 角色菜单弹窗把必要父目录按级联展开为全部子菜单 | 管理员看到并可能保存未授权菜单，造成权限扩大          | 租户管理员、业务用户     | L3；授权数据安全 | GitHub Issue #918、`RoleView` 最新 main 代码                |
| BP-002 | 企微同步把主部门 ID 写入租户主体 `partyId`     | 已分配角色与登录授权上下文不一致，菜单和 API 权限失效 | 企微同步员工、租户管理员 | L3；核心业务阻断 | GitHub Issue #918、Notice/Auth/Authorization 最新 main 代码 |
| BP-003 | 默认 demo 暴露多个租户，但多数功能只初始化租户 1 | 第二租户大量页面为空，多租户概念增加理解和维护成本 | 平台管理员、Mango 使用者 | L3；租户产品边界 | 用户 2026-09-01 明确要求改为单租户模式 |

| ------ | ---------- | ---------------- | -------------------------------- | ---------------------------------------------------------------------------- | -------------------- | ------------------------------------------------ |
