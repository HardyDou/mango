# PLAN-CMS-DEBT 审批记录

- 审批人：HardyDou（当前仓库所有者与会话用户）
- 审批日期：2026-07-14
- 审批结论：批准在一个 CMS 任务分支内按检查点实施并一次性交付。
- 审批依据：用户批准推荐方案，并要求持续推进所有模块，不在 CMS 阶段重复停顿。
- 实施顺序：书面门禁→测试补强→生产代码未改时记录 before→领域与协议治理→DDL/资源治理→同入口 after→新库服务/API/UI 终验→合并最新 main→PR/CI。
- 停止条件：公共契约或业务不变量差异、非公开数据泄露、V1 结构不一致、Demo 默认加载、架构债务未归零或 required check 失败。
- 检查范围：只验证 CMS 直接修改模块和必要 PMO 交付物，不执行全仓检查。
